# Sıla’yı tek gecede doktor eden çalışma notu

İki psikiyatri çıkmış soru derlemesinden 113 açıklamalı kart. Tanı soruları DSM-5 çerçevesini izler. Tedavi ve ilaç soruları klinik kaynaklara dayanır.

`index.html` dosyasını tarayıcıda açarak çalışabilir, yanıtları gizleyebilir ve yanlışlarını tekrar edebilirsin. İlerleme ve notlar kullandığın tarayıcıda saklanır.
